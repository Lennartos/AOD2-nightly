# Arsenal of Democracy 2 — nightly builds

Beta builds of Arsenal of Democracy 2, rebuilt every night from the latest development version. This repository
holds only the downloads; there is no source code here.

**Download the newest build:** https://github.com/Lennartos/AOD2-nightly/releases/download/nightly/AOD2-nightly.zip
([release page](https://github.com/Lennartos/AOD2-nightly/releases/tag/nightly), with the date and what changed)

Unzip it anywhere and run `AOD.exe`. Windows 64-bit only.

These are untested development builds: expect bugs, and expect saves from one night not to load the next.

## Feedback

Press **F12** in the game to send a bug report (it includes a screenshot, your save and the log). Talk to us on the
Arsenal of Democracy Discord: https://discord.gg/RvjKrGYwx6
